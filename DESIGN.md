# QNeuro Forge — Design Document

## Aesthetic Direction
A lab notebook crossed with a notarised instrument printout. Warm paper, ink, hairline rules, monospaced data. It must look authored by a person who reads papers, not generated by a template.

## Colour Tokens (no other colours permitted)
- `--paper`:    #ECE8DC (page background)
- `--paper-2`:  #E2DDCE (row banding, hairline rules)
- `--ink`:      #1C1B18 (primary text, lines)
- `--ink-2`:    #5B574D (secondary text)
- `--verdigris`:#1E6B55 (quantum series, "verified" stamp)
- `--brass`:    #86600F (warnings only)
- `--oxide`:    #A83224 (tampered, failed)

## Typography
- Display and verdict sentences: Instrument Serif (regular and italic). Fallback: Georgia, serif.
- Body prose: IBM Plex Sans. Fallback: sans-serif.
- All numbers, labels, hashes, table cells: IBM Plex Mono. Fallback: ui-monospace, monospace.
- Scale: base 15px, ratio 1.25, defined strictly as CSS custom properties:
  - `--step--2`: 9.6px
  - `--step--1`: 12px
  - `--step-0`: 15px (base)
  - `--step-1`: 18.75px
  - `--step-2`: 23.44px
  - `--step-3`: 29.30px
  - `--step-4`: 36.62px
- No other font sizes are permitted.
- Spacing tokens: 5px, 9px, 14px, 23px, 37px, 60px. No other spacing values.

## Hard Bans (any violation is a defect)
- Fonts: Inter, Roboto, Arial, Space Grotesk, Geist, Plus Jakarta Sans, system-ui as primary font.
- Colours: any blue, indigo, violet, purple, cyan-blue or pink-purple. Any orange or terracotta near #D97757.
- Gradients anywhere: backgrounds, text, buttons, borders. No glow, blur, glassmorphism, blobs.
- box-shadow of any kind.
- border-radius above 2px (use 0 or 2px max).
- Cards inside cards. Three equal feature cards in a row. A hero section. Eyebrow labels above headings.
- "Live" badges, pulsing dots, spinners, skeleton shimmer.
- Emoji, icon libraries, stock illustrations.
- Tailwind, Bootstrap, component libraries, UI kits, Plotly or Chart.js default themes.
- Round-number stat tiles ("99%", "10x"), lorem ipsum, placeholder names.
- Marketing words: seamless, powerful, revolutionary, unlock, leverage, next-gen, cutting-edge, supercharge.

## Layout Structure
Single page, asymmetric, hairline 1px ink rules to separate regions. No boxes around everything.
1. Header strip: wordmark left in serif, run id and UTC timestamp right in mono.
2. Verdict: one serif sentence at the largest scale step (`--step-4`), generated from guard output with real numbers (winning model, AUROC gap, 95% confidence interval, corrected p-value).
3. Two columns below:
   - Left 5/12: run ledger table (IBM Plex Mono, banded rows using `--paper-2`).
   - Right 7/12: horizontal interval plot (mean AUROC dot plus CI whisker per model, sorted, direct labels, no legend, no gridlines beyond axis ticks; quantum series in verdigris, best classical in ink, rest in ink-2).
4. Agent log: ruled vertical list, each row has step number, action in mono, agent's stated reason in Plex Sans.
5. Provenance: signature status as a rectangular stamp (verdigris "SIGNATURE VALID" or oxide "TAMPERED"), public key fingerprint, audit chain head hash, "Verify a file" input.
Mobile at 390px: single column, plot scrolls horizontally inside its own container.

## Required UI States
- Empty: no runs yet. Show exact CLI command to run in mono.
- Running: step counter as text ("step 3 of 8"), no animation.
- Error: what failed, the file or stage, and the command to retry.
- Tampered: oxide band across the top, naming the first audit entry index or field whose hash fails.

## Copy Policy
Describe what happened using the run's numbers in plain sentences. If a sentence could appear on any other product's site, rewrite it.
